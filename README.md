# apk-utils

A collection of tools and checklists for Android bug hunting

## Scripts

| Script                      | Description                                                          |
| --------------------------- | -------------------------------------------------------------------- |
| [`pull apk`](./pull%20apk/) | Search for an installed package and pull only its `base.apk` via ADB |

## Conventions

- Every tool folder has its own `README.md` with usage instructions.
- if a tool needs extra packages, its
  README will say so and include a `requirements.txt`.
